# Problem

Users reported that new tickets did not trigger the `windows-ticket-notifier` PowerShell toast alerts.

## Root Causes Found

1. **Missing database tables**: `notifications` and `notification_recipients` tables did not exist in the MySQL schema, so `notifyNewTicket()` in `includes/functions_notification.php` failed silently.
2. **Defective PowerShell login flow**: `windows-ticket-notifie.ps1` referenced undefined functions (`Connect-ToRomar`, `Get-RomarNotifications`) and contained malformed lines (`NaN`, `$Password` vs `$plainPassword` mismatch).

## Changes Made

- **Database migration** (`database/migrations/002_update_notification_tables.sql`) creates `notifications` & `notification_recipients` tables.
- **Migration runner** (`scripts/run_notification_migration.php`) executes the migration safely.
- **Updated main schema** (`database/schema_mysql.sql`) now includes the notification tables.
- **Rewrote `scripts/windows-ticket-notifier.ps1`**:
  - Implemented `Connect-ToRomar` and `Get-RomarNotifications` functions.
  - Fixed credential-to-plaintext conversion.
  - Restored full login + polling + toast loop with BurntToast.
- **Added `scripts/setup-windows-notifier.ps1`** – helper to install BurntToast and create a Windows Scheduled Task.
- **Added `tests/notification_api_test.php`** – standalone test script to verify notifications can be created and fetched.
- **Updated TODOs**: `TODO_WINDOWS_NOTIFICATIONS.md`, `TODO_NOTIFICATION_FIX.md` with step-by-step verification.

## Testing

- Migration was applied successfully (`php scripts/run_notification_migration.php`).
- `notification_api_test.php` passed with `SUCCESS: All tests passed!`.
- Windows notifier script runs interactively and shows toasts for unread notifications.

## Deployment Notes

1. Run the migration on the target database.
2. Update the `BaseUrl` param in the scheduled task if the server URL differs from the default (`http://localhost/Romar`).
3. Ensure the Windows user running the notifier has BurntToast installed (the setup script handles this).
